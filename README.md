# Pappilon (website, wiki and guide)

This repository holds the **public website** for Pappilon, a free research app where women commuters map how public-transport journeys feel, so cities can be designed to feel safer.

It contains three things for participants and visitors:

* a **landing page** with a project video, the story of the project, the team and supporters
* a searchable **wiki** that explains the app in plain language
* an illustrated **user guide** (PDF)

The app's source code is in a separate repository: [APP-REPO](https://github.com/gautamiitbmonash/pappilon).

[Website](https://gautamiitbmonash.github.io/pappilon/) · [Open the app](https://gautamiitbmonash.github.io/pappilon/) · [Wiki](https://gautamiitbmonash.github.io/pappilonproject/wiki.html) · [User guide (PDF)](https://gautamiitbmonash.github.io/pappilonproject//user-guide.pdf)
